Deskripsi Website

Website ini dirancang untuk membandingkan performa antara metode Iteratif dan Rekursif. Melalui analisis waktu eksekusi yang presisi, pengguna dapat memahami kapan harus menggunakan pengulangan standar atau pemanggilan fungsi diri sendiri.

Fitur utama meliputi input data kustom, pengukuran waktu menggunakan performance.now(), serta visualisasi data interaktif menggunakan Chart.js.

Referensi & Teknologi

Teknologi: HTML5, CSS3 Modern, JavaScript (ES6).

Library: Chart.js untuk visualisasi data.

Dokumentasi: MDN Web Docs

Konsep Dasar

Algoritma Iteratif

Menggunakan perulangan (loop) seperti for atau while. Lebih hemat memori karena tidak menambah beban pada stack pemanggilan fungsi.

Algoritma Rekursif

Memecahkan masalah dengan memanggil dirinya sendiri. Lebih elegan untuk struktur data kompleks seperti Tree, namun berisiko Stack Overflow jika terlalu dalam.

Perbandingan Performa

Secara umum, Iteratif memiliki kecepatan yang sedikit lebih unggul pada operasi sederhana, sedangkan Rekursif menawarkan kemudahan penulisan kode pada masalah yang bersifat hierarkis.
